## GPL-3.0 obligations

Klipper, Moonraker, Mainsail and mainsail-config are licensed under the GNU
General Public License version 3. Distributing the app image means
distributing these programs, so the project:

* ships Klipper, Moonraker and mainsail-config **as source code** inside the
  image (Python and configuration files under `/opt`), together with their
  license files (`/opt/klipper/COPYING`, `/opt/moonraker/LICENSE`,
  `/opt/mainsail-config/LICENSE`);
* builds Mainsail from the exact upstream tag listed above **without
  modifications**, using `vite build --base=/__KHAOS_BASE__/` and the
  environment variable `VUE_APP_PATH=/__KHAOS_BASE__` (see
  `klipper/Dockerfile`). The complete corresponding source is the upstream
  tag plus those build settings, which are part of this repository. At
  runtime nginx replaces the placeholder string `/__KHAOS_BASE__` in the
  served files with the actual URL prefix;
* pins every component to an exact commit so the corresponding source can
  always be identified;
* keeps the build recipe (`klipper/Dockerfile`) public, which is the
  "scripts used to control compilation and installation".

an image version, the maintainers will provide the complete corresponding
source code of the GPL-licensed components contained in that image, on
request through a GitHub issue in this repository, at no charge beyond the
cost of physically performing the transfer (normally: free download).

## Firmware binaries

Firmware files attached to GitHub releases (`*-klipper.bin`) are compiled
from the Klipper source at the commit listed above (GPL-3.0) using
`tools/build-firmware.sh` and the configuration in `firmware/`. The source
for every binary is that Klipper commit plus the configuration file.

## Printer profiles

The printer profiles under
`klipper/rootfs/usr/share/klipper-haos/profiles/` are original work of this
project (MIT). Pin assignments are hardware facts that were cross-checked
against community configurations, which are credited in
[docs/printer-setup.md](docs/printer-setup.md); no text from those
configurations was copied, because they are published without a license.

## Logo and icon

`klipper/icon.png` and `klipper/logo.png` are original artwork generated by
`tools/make-icons.py` (MIT). They do not use the Klipper, Mainsail or Home
Assistant logos.
