# Home Assistant App: Klipper

Klipper, Moonraker and Mainsail running on Home Assistant OS. Turn your Home
Assistant machine into a 3D printer host: no Raspberry Pi needed.

![Supports amd64 Architecture][amd64-shield]
![Project Stage][stage-shield]

* Mainsail in the Home Assistant sidebar (Ingress)
* Optional Moonraker API port for slicers (API key required)
* Persistent configuration and G-code files, included in backups
* Safe defaults: no motion and no heaters until you load a printer profile

> **Experimental.** Runs on Home Assistant OS but is not yet validated with
> a real printer. Read the Documentation tab before connecting a printer.
